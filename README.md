# House Sales Analysis

This project explores historical house sales data from King County, WA.

## Tools Used
- Python
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebook

## Key Features
- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Visualization of sales trends
- Correlation analysis of price-driving features

## Goal
To identify key factors affecting house prices and support better pricing decisions.
